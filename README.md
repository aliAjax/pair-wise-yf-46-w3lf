# pair-wise-yf-46 国际新闻直播编排与突发插播控制台

源提示词摘要：面向导播、主编、字幕和演播室岗位的直播串联单，维护新闻片、连线、嘉宾、口播和广告；支持时长重算、硬时间风险、突发插播、角色权限、操作历史、一键撤回和断网应急队列。

## 技术栈

React19、TypeScript、Vite、Ant Design、Redux Toolkit、RTK Query、React Router、React Hook Form、Zod、i18next、date-fns、dnd-kit。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

开发端口：62011

## 可恢复编排账

串联单、突发插播、应急队列与硬时间共用同一份**版本化账本**（`src/ledger/`），所有变更以操作（op）入账：

- **版本与并发冲突**：每个条目有 `version`，账本有 `ledgerVersion`。两个岗位基于同一版本改同一段落时，先确认的入账，后到的判为 `conflict` 挂起并列出字段差异，不会覆盖已确认版本；可「保留我方重放」或「采用对方确认版」。
- **硬时间重算**：时长或插播变化后，从未开播段落起按已播出时长累加，超过 `hardStart` 立即标红风险；已播出记录归入留档，不再参与重算。
- **断网排队 / 回连合并**：离线时操作只进应急队列（`outbox`），回连后按操作序号合并。突发插播按内容指纹幂等（同一插播只入库一次）；写入失败的操作标 `failed`，重试时只处理未写入部分，已写入的自动跳过。
- **旧数据迁移**：首次打开无版本号的旧数据时自动补 `v1`，已播出记录归入留档。
- **岗位权限**：导播可全部操作；主编可新增/插播/取消但不能调时长、顺序、确认播出；字幕只能改标题/主播/来源文字；演播室只能确认播出/取消。越权直接拒绝并入账审计。

账本持久化在 `localStorage`（`pair-wise-yf-46/ledger/v1`），操作账本页可查看全部 op 的序号、岗位、版本、状态与原因。
